# Examples: outside-in readiness runs on real DFW manufacturers

> **Outside-in illustrations built only from public information. Not affiliated with, endorsed by, or reviewed by any company listed. Systems and checklist answers are assumptions, not facts about any company's internal operations. Generated by an LLM pipeline; not a professional assessment.**

These examples show how ResonanceForge handles a realistic intake. Each one picks a single workflow that fits a real Dallas–Fort Worth manufacturer's public footprint (10-K filings, company sites, press releases) and runs the four-agent pipeline on it. The primary demo is still the fictional [Red River Components](../demo-case.md) case.

## How these were built

1. **Company selection:** a mid-market or small-cap manufacturer headquartered or with plants in DFW, verified against the company's own site and at least one other source (SEC filing, press release or news).
2. **Intake:** written only from public sources. Anything inferred, such as an ERP vendor, is labeled as assumed in the situation text.
3. **Checklist answers:** none of this is public, so all 15 answers are neutral, conservative assumptions, mostly 2–3 on a 1–5 scale. A real assessment would replace them with the company's own answers. Readiness-dimension scores come from these answers through a deterministic rubric, so the scores say more about the assumption set than about the company.
4. **Run:** one live run per company through `POST /api/assessments/stream` (Groq `openai/gpt-oss-120b`), with screenshots taken from the share page.

## Reproduce

```bash
for s in ennis parker-food-group optex-systems; do
  curl -N -X POST http://127.0.0.1:8000/api/assessments/stream \
    -H "Content-Type: application/json" -H "X-Demo-Token: $DEMO_TOKEN" \
    --data @docs/examples/$s/intake.json
  sleep 90   # stay under the Groq free-tier token limit
done
```

Pilot zips are not committed. Each run writes its own under `DATA_DIR`.
